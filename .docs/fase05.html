A base de autores entra por um seed

Requisitos: RF03, RF04

🎯 Objetivo

Popular autores com quatro fichas. A base de autores não é criada pela API: ela é uma cópia de uma base externa, e entra no sistema por fora. Essa decisão parece burocrática agora e vira arquitetura na fase 47.

👨‍💻 O que você digita

Um array de constantes e um INSERT OR IGNORE, que torna o seed idempotente: rodar a aplicação dez vezes não duplica nada.

⚠️ Repare que o id vai explícito no INSERT. Sem ele, o OR IGNORE não teria conflito nenhum para ignorar — nome não é único — e cada bun run start acrescentaria mais quatro autores. Idempotência não vem do OR IGNORE; vem de existir uma chave que possa colidir.

Repare que nenhum dos quatro tem ORCID. Três morreram antes de o registro existir, e o quarto simplesmente não tem um. É exatamente por isso que a chave primária é o id — e é esse o assunto da fase 33.

src/db.ts — arquivo completo, com as mudanças marcadas

typescript
import { Database } from "bun:sqlite";

export const db = new Database("data/biblioteca.sqlite", { create: true });

db.run("PRAGMA foreign_keys = ON;");

// O id vai explícito de propósito: é ele que faz o INSERT OR IGNORE ser
// idempotente, e é ele que os exemplos deste documento referenciam.
// O ORCID é nulo para os quatro — três morreram antes de ele existir.
const AUTORES = [
  [1, "Eric Evans"],
  [2, "Robert C. Martin"],
  [3, "Harper Lee"],
  [4, "Jane Austen"],
] as const;

function seedAutores() {
  const insert = db.prepare(
    "INSERT OR IGNORE INTO autores (id, nome) VALUES (?, ?)",
  );

  for (const [id, nome] of AUTORES) {
    insert.run(id, nome);
  }
}

export function createDb() {
  db.run(`
    CREATE TABLE IF NOT EXISTS autores (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      nome TEXT NOT NULL,
      orcid TEXT UNIQUE
    );
  `);

  seedAutores();

  console.log("Banco de dados inicializado.");
}

✅ Como testar

terminal
bun run start
sqlite3 data/biblioteca.sqlite "SELECT id, nome FROM autores;"
saída
1|Eric Evans
2|Robert C. Martin
3|Harper Lee
4|Jane Austen

Rode bun run start de novo e confira que continuam quatro linhas.
