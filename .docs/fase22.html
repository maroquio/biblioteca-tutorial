💣 GOLPE 2 — o limite muda, e só metade do sistema fica sabendo

Requisitos: RF05′

🎯 Objetivo

O RF05 muda: a direção da biblioteca decidiu que o limite passa de três para cinco, e que autores didáticos — os adotados em disciplina — podem ter dez livros. Requisito trivial. Implemente — e não olhe para o src/importar.ts.

👨‍💻 O que você digita

São quatro mudanças:

  1. schema: autores ganha a coluna tipo ('literatura' por padrão);
  2. o seed passa a informar o tipo de cada autor;
  3. POST /livros calcula o limite a partir do tipo do autor;
  4. os testes são atualizados para a regra nova.

Repare que o item 1 não é uma migração: CREATE TABLE IF NOT EXISTS não altera tabela que já existe, e a coluna só aparece porque a verificação apaga o banco antes de rodar. Num banco de verdade, com dados, a coluna nunca surgiria e o limite cairia para cinco em silêncio — sem erro nenhum. Este documento recria o banco o tempo todo e por isso escapa; sistemas em produção não escapam, e é daí que vem a disciplina de migração versionada.

Faça exatamente isso — e não olhe para src/importar.ts. Você não tem motivo para olhar: você foi ao lugar onde a regra estava, e mudou.

export const db = new Database("data/biblioteca.sqlite", { create: true });

// O id vai explícito de propósito: é ele que faz o INSERT OR IGNORE ser
// idempotente, e é ele que os exemplos deste documento referenciam.
// O ORCID é nulo para os quatro — três morreram antes de ele existir.
const AUTORES = [
  [1, "Eric Evans", "didatico"],
  [2, "Robert C. Martin", "didatico"],
  [3, "Harper Lee", "literatura"],
  [4, "Jane Austen", "literatura"],
] as const;

function seedAutores() {
  const insert = db.prepare(
    "INSERT OR IGNORE INTO autores (id, nome, tipo) VALUES (?, ?, ?)",
  );

  for (const [id, nome, tipo] of AUTORES) {
    insert.run(id, nome, tipo);
  }
}

export function createDb() {
  db.run(`
    CREATE TABLE IF NOT EXISTS autores (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      nome TEXT NOT NULL,
      orcid TEXT UNIQUE,
      tipo TEXT NOT NULL DEFAULT 'literatura'
    );
  `);

  db.run(`
    CREATE TABLE IF NOT EXISTS livros (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      numero_registro TEXT NOT NULL UNIQUE,
      isbn TEXT NOT NULL UNIQUE,
      titulo TEXT NOT NULL,
      autor_id INTEGER NOT NULL,
      data_catalogacao TEXT NOT NULL,
      FOREIGN KEY (autor_id) REFERENCES autores(id)
    );
  `);

  seedAutores();

  console.log("Banco de dados inicializado.");
}

type Handler = (
  request: Request,
  params: Record<string, string>,
) => Response | Promise<Response>;

type Route = { method: string; pattern: string; handler: Handler };

function match(pattern: string, path: string): Record<string, string> | null {
  const patternParts = pattern.split("/").filter(Boolean);
  const pathParts = path.split("/").filter(Boolean);

  if (patternParts.length !== pathParts.length) return null;

  const params: Record<string, string> = {};

  for (let i = 0; i < patternParts.length; i++) {
    const expected = patternParts[i]!;
    const received = pathParts[i]!;

    if (expected.startsWith(":")) {
      params[expected.slice(1)] = received;
    } else if (expected !== received) {
      return null;
    }
  }

  return params;
}

        )

function isbnSintetico(seq: number): string {
  const doze = `97800000${String(seq).padStart(4, "0")}`;
  let soma = 0;

  for (let i = 0; i < 12; i++) soma += Number(doze[i]!) * (i % 2 === 0 ? 1 : 3);

  return doze + ((10 - (soma % 10)) % 10);
}
