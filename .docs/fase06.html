Tabela livros, com chave estrangeira

Requisitos: RF01

🎯 Objetivo

Criar a tabela livros, base do RF01, ligada a autores por uma chave estrangeira — a mesma que vamos remover, deliberadamente, na fase 50. O campo isbn nasce UNIQUE: é o que sustenta o RF08, e é a única regra deste sistema que o banco consegue impor sozinho.

👨‍💻 O que você digita

Note os dois UNIQUE, e que eles são de naturezas diferentes.

numero_registro é a identidade que a biblioteca grava na etiqueta: nós a atribuímos, sequencialmente, a partir da fase 15.

isbn vem de fora e apenas conferimos: é ele que vai sustentar o RF08 na fase 16 — e é ele que vai salvar o sistema da corrida entre o SELECT e o INSERT que aquela fase expõe.

src/db.ts — arquivo completo, com as mudanças marcadas

typescript
import { Database } from "bun:sqlite";

export const db = new Database("data/biblioteca.sqlite", { create: true });

db.run("PRAGMA foreign_keys = ON;");

// O id vai explícito de propósito: é ele que faz o INSERT OR IGNORE ser
// idempotente, e é ele que os exemplos deste documento referenciam.
// O ORCID é nulo para os quatro — três morreram antes de ele existir.
const AUTORES = [
  [1, "Eric Evans"],
  [2, "Robert C. Martin"],
  [3, "Harper Lee"],
  [4, "Jane Austen"],
] as const;

function seedAutores() {
  const insert = db.prepare(
    "INSERT OR IGNORE INTO autores (id, nome) VALUES (?, ?)",
  );

  for (const [id, nome] of AUTORES) {
    insert.run(id, nome);
  }
}

export function createDb() {
  db.run(`
    CREATE TABLE IF NOT EXISTS autores (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      nome TEXT NOT NULL,
      orcid TEXT UNIQUE
    );
  `);

  db.run(`
    CREATE TABLE IF NOT EXISTS livros (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      numero_registro TEXT NOT NULL UNIQUE,
      isbn TEXT NOT NULL UNIQUE,
      titulo TEXT NOT NULL,
      autor_id INTEGER NOT NULL,
      data_catalogacao TEXT NOT NULL,
      FOREIGN KEY (autor_id) REFERENCES autores(id)
    );
  `);

  seedAutores();

  console.log("Banco de dados inicializado.");
}

✅ Como testar

terminal
rm -f data/biblioteca.sqlite && bun run start
sqlite3 data/biblioteca.sqlite ".tables"
sqlite3 data/biblioteca.sqlite "PRAGMA foreign_key_list(livros);"
saída
autores  livros
saída
0|0|autores|autor_id|id|NO ACTION|NO ACTION|NONE

Na linha do PRAGMA, autor_id é a coluna daqui e id é a coluna de lá: a chave estrangeira lê-se "livros.autor_id aponta para autores.id".
