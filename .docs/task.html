Scripts dev e start

🎯 Objetivo

Criar os scripts dev (com --watch, que reinicia o processo a cada alteração) e start, e apontar o package.json para src/index.ts. A partir daqui você roda o projeto com bun run dev e não pensa mais no caminho do arquivo.

👨‍💻 O que você digita

package.json — arquivo completo, com as mudanças marcadas

typescript
{
  "name": "biblioteca",
  "module": "src/index.ts",
  "type": "module",
  "private": true,
  "scripts": {
    "dev": "bun --watch src/index.ts",
    "start": "bun src/index.ts"
  },
  "devDependencies": {
    "@types/bun": "latest"
  },
  "peerDependencies": {
    "typescript": "^7"
  }
}
