As ports de repositório, declaradas no domínio

🎯 Objetivo

Inverter a dependência: as interfaces de repositório passam a ser declaradas no domínio, junto de quem as usa. Nenhuma implementação muda nesta fase — são só contratos. Entra também a port Clock, porque "que dia é hoje" é dependência externa como qualquer outra.

👨‍💻 O que você digita

Três arquivos, nenhuma linha de comportamento. Clock é a port que vai tornar o RF06 e o RF07 testáveis de forma determinística.

src/domain/Clock.ts — arquivo novo

typescript
/**
 * Port: "que dia é hoje" é uma dependência externa como qualquer outra.
 * Enquanto o domínio chamar `new Date()` sozinho, ele é intestável no tempo —
 * e o número de registro depende do ano.
 */
export type Clock = () => Date;

src/domain/LivroRepository.ts — arquivo novo

typescript
import type { AutorId } from "./identifiers";
import type { Isbn } from "./Isbn";
import type { Livro } from "./Livro";

/**
 * Port: quem PRECISA do serviço declara o contrato. Esta interface vive no
 * domínio e não sabe que existe SQLite, HTTP ou qualquer outra tecnologia.
 * Repare que as duas primeiras assinaturas são perguntas de negócio, não
 * consultas.
 */
export interface LivroRepository {
  contarNoAcervoDoAutor(autorId: AutorId): number;
  contarCatalogadosNoAno(ano: string): number;

  insert(livro: Livro): Livro;
  findByIsbn(isbn: Isbn): Livro | null;
  findByAutorId(autorId: AutorId): Livro[];
  searchByTitulo(termo: string): Livro[];

  // ⚠️ uma pergunta sobre AUTORES, feita ao repositório de LIVROS. Fase 50.
  searchByNomeDoAutor(termo: string): Livro[];
}

Os nomes vêm da fase 30, sem o prefixo Livro — ele já está no nome da interface. E repare na última assinatura, porque ela é a única fora do lugar: searchByNomeDoAutor é uma pergunta sobre autores que o domínio do livro está fazendo ao próprio repositório. É o JOIN da fase 11, agora com nome de contrato. A fase 50 cobra.

src/domain/AutorRepository.ts — arquivo novo

typescript
import type { Autor } from "./Autor";
import type { AutorId } from "./identifiers";

export interface AutorRepository {
  findById(autorId: AutorId): Autor | null;
}

Uma assinatura só, e os dois casos de uso dependem dela: o Cadastrar Livro para conferir o RF04, o Buscar Livro para pôr o nome do autor na resposta. E é por isso que a port fica no domínio e não na infraestrutura — quem decide o que precisa ser perguntado ao banco é quem tem a pergunta, não quem tem o banco.
