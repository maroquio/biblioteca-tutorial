O pedido da biblioteca

Leitores podem registrar avaliações dos livros catalogados. A API recebe POST /avaliacoes com numeroRegistro, matricula, nota inteira de 1 a 5 e comentario opcional. Uma matrícula pode avaliar o mesmo livro uma única vez.

Livro inexistente resulta em 404; segunda avaliação da mesma matrícula para o mesmo número de registro resulta em 409; entrada inválida resulta em 400. O sucesso retorna 201, Location: /avaliacoes/:id e um JSON com os cinco campos recebidos mais id. Comentário ausente é null.

Esta atividade também parte da main; não depende da Atividade 5. Todos os blocos de lógica são copiáveis. Você completa os imports locais e as ligações entre artefatos. Nenhum enunciado fornece o caminho dos arquivos novos.

Os blocos marcados arquivo novo formam o corpo principal de um arquivo. Os de edição entram em artefatos existentes. Faça o projeto compilar acrescentando os imports locais apropriados.

Entidade do módulo

A nota válida é decisão da entidade. A matrícula e o número de registro já chegam como textos não vazios da entrada.

TypeScript 
export class Avaliacao {
  constructor(
    readonly id: AvaliacaoId | null,
    readonly numeroRegistro: string,
    readonly matricula: string,
    readonly nota: number,
    readonly comentario: string | null,
  ) {
    if (!Number.isInteger(nota) || nota < 1 || nota > 5) {
      throw new InvalidValue("A nota deve ser um inteiro de 1 a 5");
    }
  }

  static registrar(
    numeroRegistro: string,
    matricula: string,
    nota: number,
    comentario: string | null,
  ): Avaliacao {
    return new Avaliacao(null, numeroRegistro, matricula, nota, comentario);
  }

  withId(id: AvaliacaoId): Avaliacao {
    return new Avaliacao(
      id, this.numeroRegistro, this.matricula, this.nota, this.comentario,
    );
  }
}

export function parseNovaAvaliacao(body: unknown): NovaAvaliacao {
  const data = getBodyAsObject(body);
  return {
    numeroRegistro: getFieldAsText(data, "numeroRegistro"),
    matricula: getFieldAsText(data, "matricula"),
    nota: getFieldAsPositiveInt(data, "nota"),
    comentario: data.comentario == null
      ? null
      : getFieldAsText(data, "comentario"),
  };
}

06 · arquivo novo

Caso de uso

O caso de uso recebe as duas portas. A consulta ao Acervo é uma pergunta de negócio; ele não vê SQLite nem importa um módulo vizinho.

TypeScript 
export class RegistrarAvaliacao {
  constructor(
    private readonly avaliacoes: AvaliacaoRepository,
    private readonly acervo: ConsultaDeAcervo,
  ) {}

  execute(input: NovaAvaliacao): AvaliacaoJson {
    if (!this.acervo.existeNumeroRegistro(input.numeroRegistro)) {
      throw new NotFound("Livro não encontrado");
    }
    if (this.avaliacoes.findByMatriculaELivro(
      input.matricula, input.numeroRegistro,
    )) {
      throw new RuleConflict("Leitor já avaliou este livro");
    }

    const avaliacao = this.avaliacoes.insert(Avaliacao.registrar(
      input.numeroRegistro,
      input.matricula,
      input.nota,
      input.comentario,
    ));
    return avaliacaoToJson(avaliacao);
  }
}
07 · arquivo novo

Rota da fatia

A rota recebe HTTP e chama o caso de uso. O servidor já transforma exceções em status.

TypeScript 
export function register(routes: Hono, useCases: UseCases): void {
  routes.post("/avaliacoes", async (contexto) => {
    const input = parseNovaAvaliacao(await contexto.req.json());
    const avaliacao = useCases.registrarAvaliacao.execute(input);
    contexto.header("Location", `/avaliacoes/${avaliacao.id}`);
    return contexto.json(avaliacao, 201);
  });
}

09 · arquivo novo

Adaptador de persistência

A implementação da porta traduz entre linhas SQL e entidade.

TypeScript 
type AvaliacaoRow = {
  id: number;
  numero_registro: string;
  matricula: string;
  nota: number;
  comentario: string | null;
};

function toAvaliacao(row: AvaliacaoRow): Avaliacao {
  return new Avaliacao(
    new AvaliacaoId(row.id), row.numero_registro,
    row.matricula, row.nota, row.comentario,
  );
}

export class SqliteAvaliacaoRepository implements AvaliacaoRepository {
  findByMatriculaELivro(
    matricula: string,
    numeroRegistro: string,
  ): Avaliacao | null {
    const row = db.query(`
      SELECT * FROM avaliacoes
      WHERE matricula = ? AND numero_registro = ?
    `).get(matricula, numeroRegistro) as AvaliacaoRow | null;
    return row === null ? null : toAvaliacao(row);
  }

  insert(avaliacao: Avaliacao): Avaliacao {
    const result = db.run(`
      INSERT INTO avaliacoes
        (numero_registro, matricula, nota, comentario)
      VALUES (?, ?, ?, ?)
    `, [
      avaliacao.numeroRegistro, avaliacao.matricula,
      avaliacao.nota, avaliacao.comentario,
    ]);
    return avaliacao.withId(new AvaliacaoId(Number(result.lastInsertRowid)));
  }
}

Conexões que você resolve

Além dos blocos, o módulo precisa de seu registro de rotas e de uma API pública mínima. Publique o contrato do Acervo por sua própria API pública. Faça a composição instanciar o repositório e a ponte, exponha o caso de uso no tipo usado pelas rotas, registre o módulo no servidor e crie sua tabela na inicialização. Atualize a verificação de propriedade das tabelas.

Não coloque a consulta ao livro em SQL dentro do módulo de Avaliações. O acesso à tabela de livros continua pertencendo ao Acervo. Não altere o comportamento das fatias existentes.
