Servidor HTTP com Bun.serve

🎯 Objetivo

Subir um servidor HTTP com Bun.serve, sem framework nenhum: responde a GET / e devolve 404 para qualquer outro caminho.

👨‍💻 O que você digita

Bun.serve() é o servidor HTTP nativo do runtime — não instalamos Express nem Hono. A função fetch recebe uma Request e devolve uma Response: é a mesma API do navegador.

src/index.ts — arquivo completo, com as mudanças marcadas

typescript
import { createDb } from "./db";

createDb();

const server = Bun.serve({
  port: 3000,

  fetch(request) {
    const url = new URL(request.url);

    if (url.pathname === "/") {
      return Response.json({ message: "API da Biblioteca" });
    }

    return Response.json({ error: "Recurso não encontrado" }, { status: 404 });
  },
});

console.log(`Servidor executando em http://localhost:${server.port}`);
