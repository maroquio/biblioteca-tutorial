O pedido da biblioteca

Um livro já catalogado teve seu ISBN digitado incorretamente. A API deve aceitar PATCH /livros/:id/isbn com {"isbn":"9780141439587"}. Livro inexistente resulta em 404; id inválido, ISBN vazio ou inválido resulta em 400; ISBN já usado por outro livro, de qualquer autor, resulta em 409.

A correção preserva id, número de registro, título, autor e data de catalogação. A resposta 200 contém exatamente id, numeroRegistro e isbn. Enviar o ISBN do próprio livro é permitido e retorna 200. Reutilize o objeto de valor Isbn existente para validar e normalizar: a saída contém somente os 13 dígitos. Corrigir ISBN não cataloga outro livro e não emite LivroCatalogado.

Você pode consultar o projeto e os quatro treinos. A lógica completa está nos oito blocos abaixo. 06 · arquivo novo

Orquestração do caso de uso

O caso de uso depende da porta do domínio. Use a busca por ISBN já existente na porta para detectar conflito com outro livro.

TypeScript 
export class CorrigirIsbn {
  constructor(private readonly livros: LivroRepository) {}

  execute(input: CorrecaoDeIsbn): IsbnCorrigidoJson {
    const id = new LivroId(input.id);
    const livro = this.livros.findById(id);
    if (!livro) throw new NotFound("Livro não encontrado");

    const isbn = new Isbn(input.isbn);
    const duplicado = this.livros.findByIsbn(isbn);
    if (duplicado && !duplicado.id?.equals(id)) {
      throw new RuleConflict("Outro livro já utiliza este ISBN");
    }

    const corrigido = livro.comIsbn(isbn);
    this.livros.updateIsbn(corrigido);
    return isbnCorrigidoToJson(corrigido);
  }
}
07 · arquivo novo

Borda HTTP da fatia

A rota traduz a requisição em entrada do caso de uso e devolve o resultado. O tratamento de exceções já é global no servidor.

TypeScript 
export function register(routes: Hono, useCases: UseCases): void {
  routes.patch("/livros/:id/isbn", async (contexto) => {
    const input = parseCorrecaoDeIsbn(
      contexto.req.param(),
      await contexto.req.json(),
    );
    return contexto.json(useCases.corrigirIsbn.execute(input), 200);
  });
}

3. Corrigir o ISBN e conferir os dados

Crie uma requisição PATCH para http://localhost:3000/livros/ID_A/isbn. Substitua ID_A pelo número retornado no cadastro; por exemplo, se o id for 1, use http://localhost:3000/livros/1/isbn. Não digite ID_A literalmente. Envie:

Espere 200 com exatamente id, numeroRegistro e isbn. Os dois primeiros mantêm os valores originais e o ISBN deve ser 9780141439587, sem hífens. Clique em Send novamente: repetir o próprio ISBN deve continuar retornando 200.

Envie GET para http://localhost:3000/livros/9780141439587 e compare com o GET anterior: id, título, autor, número de registro, data de catalogação e livrosDoAutor devem permanecer iguais. A consulta ao ISBN antigo, http://localhost:3000/livros/9780141439518, deve retornar 200 com lista vazia neste banco de teste.
