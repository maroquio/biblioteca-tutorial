O pedido da biblioteca

Um livro já catalogado pode ter seu título corrigido. A API deve aceitar PATCH /livros/:id/titulo com {"titulo":"Novo título"}. Se o livro não existir, responda 404. Se o título for vazio, responda 400. Se outro livro do mesmo autor já tiver título equivalente, ignorando caixa e espaços nas pontas, responda 409.

A correção preserva id, ISBN, número de registro, autor e data de catalogação. A resposta 200 contém id, isbn e titulo. Corrigir título não cataloga um livro novo e não emite LivroCatalogado.

Você pode consultar o projeto e os quatro treinos. Os blocos abaixo trazem a lógica completa. Os imports locais, os caminhos dos arquivos novos e as ligações entre artefatos são parte da avaliação.

Entrada da fatia

A entrada reúne o id da URL e o corpo JSON. Use os helpers compartilhados já existentes; descubra o import local deles.

export type CorrecaoDeTitulo = {
  id: number;
  titulo: string;
};

export function parseCorrecaoDeTitulo(
  params: { id?: string },
  body: unknown,
): CorrecaoDeTitulo {
  const data = getBodyAsObject(body);
  return {
    id: getFieldAsPositiveInt(params, "id"),
    titulo: getFieldAsText(data, "titulo"),
  };
}

06 · arquivo novo

Orquestração do caso de uso

O caso de uso depende da porta do domínio. Preserve a regra de duplicidade por autor que o cadastro de livros já pratica.

TypeScript 
export class CorrigirTitulo {
  constructor(private readonly livros: LivroRepository) {}

  execute(input: CorrecaoDeTitulo): TituloCorrigidoJson {
    const id = new LivroId(input.id);
    const livro = this.livros.findById(id);
    if (!livro) throw new NotFound("Livro não encontrado");

    const corrigido = livro.comTitulo(input.titulo);
    const duplicado = this.livros.findByAutorId(livro.autorId).some(
      (outro) => !outro.id?.equals(id) && outro.mesmoTituloQue(corrigido.titulo),
    );
    if (duplicado) {
      throw new RuleConflict("Este autor já tem um livro com este título");
    }

    this.livros.updateTitulo(corrigido);
    return tituloCorrigidoToJson(corrigido);
  }
}

Borda HTTP da fatia

A rota traduz a requisição em entrada do caso de uso e devolve o resultado. O tratamento de exceções já é global no servidor.

TypeScript 
export function register(routes: Hono, useCases: UseCases): void {
  routes.patch("/livros/:id/titulo", async (contexto) => {
    const input = parseCorrecaoDeTitulo(
      contexto.req.param(),
      await contexto.req.json(),
    );
    return contexto.json(useCases.corrigirTitulo.execute(input), 200);
  });
}

Ligações a resolver

Depois de distribuir os blocos, complete os imports locais e conecte a nova rota ao conjunto de rotas do Acervo. Publique apenas o caso de uso necessário pela API pública do módulo e monte sua instância no ponto de composição. Não altere a Autoria nem o servidor global.

Observe também as direções das dependências: o caso de uso conhece a interface do repositório; somente a implementação de infraestrutura conhece SQL.

Como conferir

Use um banco de desenvolvimento e cadastre um livro pela API existente. Em seguida, envie PATCH /livros/1/titulo com {"titulo":"Título corrigido"} e confira a resposta 200. Experimente id inexistente, título vazio e título duplicado para o mesmo autor.
